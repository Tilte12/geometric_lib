# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a

# Geometric Lib

## Общее описание

Geometric Lib — библиотека на языке Python для выполнения
геометрических вычислений.

В библиотеке находятся функции для вычисления площади
и периметра различных геометрических фигур.

## Функции

### Круг

Файл `circle.py`.

#### area

Вычисляет площадь круга.

Пример вызова:

```
python
area(2)
```

#### perimeter

Вычисляет длину окружности.

Пример вызова:

```
python
perimeter(2)
```

### Квадрат

Файл `square.py`.

#### area

Вычисляет площадь квадрата.

Пример вызова:

```
python
area(5)
```

#### perimeter

Вычисляет периметр квадрата.

Пример вызова:

```
python
perimeter(5)
```
