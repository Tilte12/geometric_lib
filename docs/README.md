
# Проект для вычисления геометрических величин

## Общее описание

Проект предназначен для вычисления площади и периметра различных геометрических фигур.

Поддерживаемые фигуры:
- Круг
- Квадрат
- Прямоугольник
- Треугольник

## Описание функций

### `circle.area(r)`

Вычисляет площадь круга.

- **Принимает:** `r` (`int`) — радиус круга.
- **Возвращает:** `float` — площадь круга.
- **Формула:** S = π × r².

**Пример:**

```python
from circle import area

print(area(5))
```

### `circle.perimeter(r)`

Вычисляет длину окружности.

- **Принимает:** `r` (`int`) — радиус круга.
- **Возвращает:** `float` — длину окружности.
- **Формула:** P = 2 × π × r.

**Пример:**

```python
from circle import perimeter

print(perimeter(5))
```

### `square.area(a)`

Вычисляет площадь квадрата.

- **Принимает:** `a` (`int`) — длина стороны квадрата.
- **Возвращает:** `int` — площадь квадрата.
- **Формула:** S = a².

**Пример:**

```python
from square import area

print(area(5))
```

### `square.perimeter(a)`

Вычисляет периметр квадрата.

- **Принимает:** `a` (`int`) — длина стороны квадрата.
- **Возвращает:** `int` — периметр квадрата.
- **Формула:** P = 4 × a.

**Пример:**

```python
from square import perimeter

print(perimeter(5))
```

### `rectangle.area(a, b)`

Вычисляет площадь прямоугольника.

- **Принимает:**
  - `a` (`int`) — длина первой стороны.
  - `b` (`int`) — длина второй стороны.
- **Возвращает:** `int` — площадь прямоугольника.
- **Формула:** S = a × b.

**Пример:**

```python
from rectangle import area

print(area(5, 10))
```

### `rectangle.perimeter(a, b)`

Вычисляет периметр прямоугольника.

- **Принимает:**
  - `a` (`int`) — длина первой стороны.
  - `b` (`int`) — длина второй стороны.
- **Возвращает:** `int` — периметр прямоугольника.
- **Формула:** P = 2 × (a + b).

**Пример:**

```python
from rectangle import perimeter

print(perimeter(5, 10))
```

### `triangle.area(a, h)`

Вычисляет площадь треугольника.

- **Принимает:**
  - `a` (`int`) — длина основания треугольника.
  - `h` (`int`) — высота, проведённая к основанию.
- **Возвращает:** `float` — площадь треугольника.
- **Формула:** S = (a × h) / 2.

**Пример:**

```python
from triangle import area

print(area(5, 10))
```

### `triangle.perimeter(a, b, c)`

Вычисляет периметр треугольника.

- **Принимает:**
  - `a` (`int`) — длина первой стороны.
  - `b` (`int`) — длина второй стороны.
  - `c` (`int`) — длина третьей стороны.
- **Возвращает:** `int` — периметр треугольника.
- **Формула:** P = a + b + c.

**Пример:**

```python
from triangle import perimeter

print(perimeter(5, 10, 15))
```
